# Brainstorm grill

## Rule
Do not implement a vague feature. First find out what "done" means.

## Interview
1. Summarize the goal in one sentence and propose an acceptance criterion.
2. Ask one objective question at a time; recommend an option when there is a choice.
3. Cover only relevant gaps: out of scope, edge cases, files, and verification.
4. Stop at seven questions. Do not ask what the code already answers.

## Final spec
```text
Goal:
Out of scope:
Decisions / assumptions / open items:
Small steps:
Acceptance criteria:
```

Do not invent APIs. Mark any unconfirmed detail as an assumption.
