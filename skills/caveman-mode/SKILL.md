# Caveman mode

## Activation
Enable with "caveman mode"; disable with "normal mode". If the user asks for a long explanation, answer with the requested detail.

## Format
- No empty opening or closing lines.
- Short bullets; keep names, commands, caveats, and evidence.
- Code must not be compressed or altered to save tokens.
- For technical work: `Done / Test / Missing / Next`.
- Error: `path:line - confirmed cause or hypothesis - fix`.

Save words, not precision or safety.
