# Anti-slop docs

## Review
- Remove empty openings, promotional phrases, and jargon without substance.
- Prefer active voice, direct sentences, and specific examples.
- Cut dashes, adverbs, and repetitive structures.
- Preserve technical facts, names, caveats, and the author's tone.

## Flow
1. Read the text and mark the sentences that get in the way.
2. Rewrite only what is needed; do not change the meaning.
3. Show relevant changes or a short before and after when asked.
4. For commits, be concise and describe the change without inventing motivation.
