# Web research

1. Run one or two specific searches.
2. Open at most two relevant sources; prefer official documentation and changelogs.
3. Separate confirmed fact from inference; record URL and date when available.
4. Summarize in a few bullets; do not dump whole pages into context.
5. If the network fails, retry once and state clearly that you did not verify.

Do not invent URLs, APIs, versions, or results. If the source does not confirm the point, say so.
